# 时间换算器

把价格换算成你真正付出的东西。

一个轻量的个人消费决策工具（移动端 H5，MVP）。输入商品价格，按你的经济来源把它换算成劳动时间、生活费天数或预算占比。不做购买建议，只帮你看清消费背后的成本。

## 三种计算模式

| 模式 | 适用人群 | 公式 |
| --- | --- | --- |
| 劳动时间 | 上班族、兼职、自由职业者 | 时薪 = 月收入 ÷（每月工作天数 × 每天工作小时数）；劳动时间 = 价格 ÷ 时薪 |
| 生活费 | 学生、依靠固定生活费的人 | 每日预算 = 每月生活费 ÷ 预算天数；生活费天数 = 价格 ÷ 每日预算 |
| 自定义预算 | 没有固定收入、依靠储蓄的人 | 预算占比 = 价格 ÷ 预算金额 × 100%；等效天数 = 价格 ÷（预算金额 ÷ 预算天数） |

自定义预算的周期：每周 7 天、每月 30 天、每季度 90 天、每年 365 天，或者自定义天数。

## 功能

- 首页实时换算，记住上次使用的模式和参数
- 首次使用引导、个人参数设置（带输入校验）
- 消费记录：保存、按日期查看、改名、删除
- 所有数据只保存在本机 `localStorage`，没有后端，也没有账号

## 开发

```bash
npm install
npm run dev      # 本地开发 http://localhost:5173
npm test         # 单元测试（Vitest）
npm run build    # 构建到 dist/
```

## 目录

- `src/calc.js`：计算和输入校验（纯函数，不依赖 DOM，可直接迁移到微信小程序）
- `src/storage.js`：设置和记录的本地存储（迁移小程序时把 `localStorage` 换成 `wx.getStorageSync` / `wx.setStorageSync`）
- `src/main.js`：页面渲染和交互（首页 `#/`、设置 `#/settings`、记录 `#/records`）
- `src/style.css`：移动端样式
- `tests/`：PRD 第十章的验收用例和异常输入测试
